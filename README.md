# Simulador de Investimentos em Fundos Imobiliários

## Sobre o projeto

Este projeto foi desenvolvido como parte do desafio da DIO,
com o objetivo de aplicar conceitos de Excel na criação de
uma ferramenta de simulação de investimentos em fundos
imobiliários (FIIs).

## Objetivo

Desenvolver uma planilha que permita simular investimentos
mensais, considerando diferentes períodos de investimento
e taxas de rendimento.

## Funcionalidades

- Cálculo do valor investido por mês;
- Simulação de investimentos em diferentes períodos;
- Cálculo do patrimônio acumulado;
- Estimativa de dividendos mensais;
- Comparação entre cenários de investimento.

## Ferramentas utilizadas

- Microsoft Excel;
- GitHub.

## Resultados

A planilha permite visualizar como os aportes mensais
e o tempo de investimento podem influenciar o patrimônio
acumulado e os dividendos estimados.
